# Customer Churn Prediction

A traditional machine learning application that predicts customer churn
using a trained scikit-learn pipeline.

## Features

- Logistic Regression churn prediction
- Estimated churn probability
- Reusable preprocessing and prediction pipeline
- Automated tests with pytest
- MLflow experiment tracking during training

## Disclaimer

Predictions are estimates based on a machine learning model and should
not be treated as guaranteed outcomes.
